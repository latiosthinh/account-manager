## Component Specifications

### 1. Header & Navigation Bar
- Top persistent header with branding title ("Account Manager"), category counter badge, "+ Add Account" primary CTA, and "Logout" icon button.
- Responsive layout: flex row with wrap for mobile viewports (<640px).

### 2. Category Navigation Tabs (`VIEW-01`)
- Horizontal pill navigation bar displaying all categories with account counts: `All (N)`, `Google (N)`, `Outlook (N)`, `[Custom Categories] (N)`.
- "+ Category" auxiliary button to trigger category creation modal.
- Active pill state: `#3b82f6` background, `#ffffff` text.
- Inactive pill state: `#1e293b` background, `#94a3b8` text, `#334155` border.
- Hover state: `#334155` background, `#f8fafc` text.

### 3. Search Bar (`VIEW-02`)
- Full-width or flex-grow search input bar with leading Search SVG icon.
- Placeholder: `Search accounts by email or category... (Ctrl+K or /)`
- Real-time client-side instant filtering across email, category name, and notes.
- Trailing clear icon button (X) when search query is non-empty.

### 4. Account Cards & Masking Controls (`MASK-01`, `MASK-02`, `MASK-03`, `MASK-04`)
- Card grid: 1 column on mobile, 2 columns on tablet, 3 columns on desktop (`grid-template-columns: repeat(auto-fill, minmax(320px, 1fr))`).
- Card Header: Category badge chip, formatted update date (`MMM d, yyyy`), and Card Actions dropdown/buttons (Edit, Delete).
- Credential Rows:
  - **Email Field**:
    - Default state (`MASK-01`): Masked format `thinh***@domain.com` (first 3-5 chars + `***@domain.com`).
    - Eye-toggle button (`MASK-03`): Toggles between masked and plaintext in client component memory (`aria-label="Toggle email visibility"`, `aria-pressed="false|true"`).
    - Quick-copy button (`MASK-04`): Copies plaintext email to clipboard. Displays temporary emerald "Copied!" tooltip/badge for 1.5 seconds (`aria-label="Copy email"`).
  - **Password Field**:
    - Default state (`MASK-02`): Masked format `••••••••`.
    - Eye-toggle button (`MASK-03`): Toggles between masked bullets and plaintext password in client component memory (`aria-label="Toggle password visibility"`, `aria-pressed="false|true"`).
    - Quick-copy button (`MASK-04`): Copies plaintext password to clipboard with 1.5s "Copied!" feedback badge (`aria-label="Copy password"`).
- Notes block: Subdued text block (`#94a3b8`) displayed when notes exist.

### 5. Modals & Dialogs
- **Add / Edit Account Modal**:
  - Fields: Category selector (dropdown with existing categories), Email address (input text), Password (input text/password with reveal toggle), Notes (textarea).
  - Action buttons: "Cancel" (secondary), "Save Account" (primary).
- **Add Category Modal**:
  - Fields: Category Name (input text).
  - Action buttons: "Cancel" (secondary), "Create Category" (primary).
- **Delete Confirmation Dialog**:
  - Explanatory prompt with item identifier.
  - Action buttons: "Cancel" (secondary), "Delete Permanently" (destructive red).

## Interaction & Accessibility Contract

- **Focus States**: All interactive elements (buttons, inputs, tabs, modal close) must feature `outline: 2px solid #3b82f6; outline-offset: 2px;` on `:focus-visible`.
- **Keyboard Navigation**:
  - `Tab` / `Shift+Tab`: Navigate focusable elements in logical reading order.
  - `Escape`: Close active modal dialog or clear search input.
  - `Ctrl+K` or `/`: Focus search input bar.
  - `Enter`: Submit form in active modal dialog.
- **ARIA Attributes**:
  - Modals: `role="dialog"`, `aria-modal="true"`, `aria-labelledby="modal-title"`.
  - Eye Reveal Buttons: `aria-label="Show password"` / `aria-label="Hide password"`, `aria-pressed="false|true"`.
  - Copy Buttons: `aria-label="Copy to clipboard"`.
  - Screen Reader Announcements: Hidden `aria-live="polite"` region for clipboard copy confirmations ("Password copied to clipboard").
