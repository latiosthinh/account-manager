  <behavior>
    - `categoriesRepo.getAllWithCounts()` returns all categories with `accountCount` integer count from `accounts` table.
    - `POST /api/categories` validates `name`: must be non-empty string, trimmed length between 1 and 50 characters, rejects duplicates case-insensitively with 400 Bad Request.
    - `GET /api/categories` returns 200 with category list including `accountCount`.
    - `DELETE /api/categories/:id` returns 400 if category is preset (`is_preset === 1`), 409 if category has `accountCount > 0`, 404 if category not found, 200 on success.
    - All `/api/categories` routes apply `requireAuth`.
  </behavior>
  <action>
    1. Update `src/db.js`:
       - Add `getAllWithCounts()` to `categoriesRepo` using SQL `LEFT JOIN accounts a ON c.id = a.category_id GROUP BY c.id ORDER BY c.is_preset DESC, c.name COLLATE NOCASE ASC` returning `id, name, is_preset, created_at, COUNT(a.id) AS account_count` (mapped to `accountCount: Number(row.account_count)`).
       - Add `getByName(name)` helper to check case-insensitive match: `SELECT * FROM categories WHERE LOWER(name) = LOWER(?)`.
    2. Create `src/routes/category-routes.js`:
       - Create Express `Router()`.
       - Apply `requireAuth` on all category router endpoints.
       - Implement `GET /` -> return `categoriesRepo.getAllWithCounts()`.
       - Implement `POST /` -> sanitize input: trim `req.body?.name`. Validate required, string, length 1..50. Check duplicate with `categoriesRepo.getByName(trimmedName)`. If invalid, return 400 with `{ error: '...' }`. If duplicate, return 400 with `{ error: 'Category already exists' }`. If valid, create category and return 201 with created object.
       - Implement `DELETE /:id` -> fetch category with `categoriesRepo.getById(id)`. If not found, return 404 `{ error: 'Category not found' }`. If `is_preset === 1`, return 400 `{ error: 'Cannot delete preset category' }`. Check account count with `accountsRepo.getByCategoryId(id)`. If count > 0, return 409 `{ error: 'Cannot delete category containing accounts' }`. Otherwise, call `categoriesRepo.delete(id)` and return 200 with `{ message: 'Category deleted successfully' }`.
    3. Update `src/server.js`:
       - Import `categoryRouter` from `./routes/category-routes.js`.
       - In `createApp()`, mount `app.use('/api/categories', categoryRouter)`.
  </action>
