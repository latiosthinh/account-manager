  <behavior>
    - `GET /api/accounts` returns array of accounts (ordered by created_at DESC). If query parameter `categoryId` provided, returns accounts filtered by category.
    - `POST /api/accounts` validates required fields `email`, `password`, `categoryId`. Validates that `categoryId` references an existing category. Trims inputs and saves optional `notes`. Returns 201 with created account object.
    - `PUT /api/accounts/:id` validates updated fields if provided. Validates `categoryId` exists if changing category. Returns 404 if account not found. Returns 200 with updated account object.
    - `DELETE /api/accounts/:id` returns 404 if account does not exist, 200 with success message on deletion.
    - All routes protected with `requireAuth`.
  </behavior>
  <action>
    1. Create `src/routes/account-routes.js`:
       - Create Express `Router()`.
       - Apply `requireAuth` on all endpoints.
       - Implement `GET /` -> check query `req.query.categoryId`. If provided, call `accountsRepo.getByCategoryId(req.query.categoryId)`; otherwise call `accountsRepo.getAll()`. Return 200 with JSON list.
       - Implement `POST /` -> sanitize and validate `email` (non-empty string, trimmed, 1-255 chars), `password` (non-empty string, 1-500 chars), `categoryId` (non-empty string, valid id), `notes` (string, max 2000 chars, default empty string).
         - Check if category exists with `categoriesRepo.getById(categoryId)`. If not, return 400 with `{ error: 'Category does not exist' }`.
         - Call `accountsRepo.create({ category_id: categoryId, email: trimmedEmail, password, notes: trimmedNotes })`. Return 201 with created account.
       - Implement `PUT /:id` -> check if account exists with `accountsRepo.getById(id)`. If not found, return 404 `{ error: 'Account not found' }`.
         - Validate any provided fields (`email`, `password`, `categoryId`, `notes`).
         - If `categoryId` provided, check `categoriesRepo.getById(categoryId)`. If missing, return 400 `{ error: 'Category does not exist' }`.
         - Call `accountsRepo.update(id, updates)`. Return 200 with updated account.
       - Implement `DELETE /:id` -> call `accountsRepo.delete(id)`. If return false, return 404 `{ error: 'Account not found' }`. Otherwise return 200 with `{ message: 'Account deleted successfully' }`.
    2. Update `src/server.js`:
       - Import `accountRouter` from `./routes/account-routes.js`.
       - Mount `app.use('/api/accounts', accountRouter)`.
