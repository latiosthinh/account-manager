  <name>Task 2: Implement timing-safe password verification and HMAC session token utilities</name>
  <files>src/auth.js, tests/auth.test.js</files>
  <behavior>
    - verifyPassword returns true for matching password and false for non-matching or empty password
    - verifyPassword digests input with SHA-256 before timingSafeEqual to avoid length disclosure
    - createSessionToken generates base64url payload with signature `payload.signature`
    - verifySessionToken accepts valid token within 7 days
    - verifySessionToken rejects tampered signature, malformed token, or expired token
  </behavior>
  <action>
    1. Create `src/auth.js` exporting:
       - `verifyPassword(inputPassword, expectedPassword)`: Hash both inputs with `crypto.createHash('sha256')` then compare buffers using `crypto.timingSafeEqual`.
       - `createSessionToken(payload, secret, maxAgeMs = 7 * 24 * 60 * 60 * 1000)`: Create JSON payload `{ ...payload, exp: Date.now() + maxAgeMs }`, encode to base64url, sign with HMAC-SHA256, return `${b64Payload}.${b64Sig}`.
       - `verifySessionToken(token, secret)`: Split token, verify HMAC-SHA256 signature using `crypto.timingSafeEqual`, parse JSON payload, ensure `exp > Date.now()`.
    2. Write unit tests in `tests/auth.test.js` using `node:test` and `node:assert`.
  </action>
  <verify>
    <automated>node --test tests/auth.test.js</automated>
  </verify>
  <done>src/auth.js implements timing-safe verification and session token signing; all tests in tests/auth.test.js pass.</done>
</task>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> Auth Utility | Untrusted password input and session tokens supplied by external requests |
| Client IP -> Rate Limiter | Untrusted remote IP address used to track brute-force attempts |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | `src/auth.js:verifyPassword` | mitigate | Hash both passwords with SHA-256 to fixed length buffers before `crypto.timingSafeEqual` comparison |
| T-01-02 | Tampering | `src/auth.js:verifySessionToken` | mitigate | Sign session payload with HMAC-SHA256; compare signatures with `crypto.timingSafeEqual` |
| T-01-03 | Denial of Service | `src/rate-limiter.js` | mitigate | Block IP after 5 failed login attempts in 15 minutes window; periodic prune of stale IP keys |
| T-01-04 | Spoofing | `src/auth.js` | mitigate | Enforce 7-day expiration timestamp in signed token payload to prevent replay of expired sessions |
</threat_model>
