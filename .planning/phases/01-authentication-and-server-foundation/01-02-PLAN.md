<task type="auto">
  <name>Task 1: Implement auth middleware and auth route handlers</name>
  <files>src/middleware/auth-middleware.js, src/routes/auth-routes.js</files>
  <action>
    1. Create `src/middleware/auth-middleware.js`:
       - Export `requireAuth(req, res, next)`: reads `req.cookies[config.cookieName]`, calls `verifySessionToken(token, config.sessionSecret)`.
       - If valid, attaches `req.user = session` and calls `next()`.
       - If missing or invalid, returns `res.status(401).json({ error: 'Unauthorized' })`.
    2. Create `src/routes/auth-routes.js`:
       - Initialize `const limiter = new LoginRateLimiter()`.
       - `POST /login`:
         - Extract client IP (`req.ip` or `req.headers['x-forwarded-for']`).
         - Check `limiter.isRateLimited(ip)` -> if limited, return `res.status(429).json({ error: 'Too many failed login attempts. Please try again later.', retryAfter: limiter.getRetryAfterSeconds(ip) })`.
         - Validate `{ password }` via `verifyPassword(password, config.adminPassword)`.
         - If password fails: `limiter.recordFailure(ip)`, return `res.status(401).json({ error: 'Invalid admin password' })`.
         - If password succeeds: `limiter.reset(ip)`, generate token via `createSessionToken({ role: 'admin' }, config.sessionSecret)`, set `res.cookie(config.cookieName, token, { httpOnly: true, secure: process.env.NODE_ENV === 'production', sameSite: 'strict', maxAge: 7 * 24 * 60 * 60 * 1000, path: '/' })`, return `res.json({ success: true, message: 'Logged in successfully' })`.
       - `POST /logout`:
         - Call `res.clearCookie(config.cookieName, { path: '/' })`, return `res.json({ success: true, message: 'Logged out successfully' })`.
       - `GET /status`:
         - Read cookie and verify token. Return `res.json({ authenticated: Boolean(isValid) })`.
  </action>
  <verify>
    <automated>node -e "import('./src/routes/auth-routes.js').then(m => console.log('AuthRouter loaded:', Boolean(m.authRouter)))"</automated>
  </verify>
  <done>Auth middleware and auth routes export required handlers matching cookie, timing-safe auth, and rate limiter specs.</done>
</task>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser Client -> Express Server | Untrusted HTTP requests containing headers, cookies, and JSON payloads |
| Untrusted Client -> Protected API Routes | Access to sensitive credential and category APIs guarded by session cookie |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-05 | Spoofing / Session Hijacking | `src/middleware/auth-middleware.js` | mitigate | Set `HttpOnly`, `SameSite=Strict`, signed HMAC tokens to prevent XSS theft and CSRF |
| T-01-06 | Denial of Service | `src/server.js` | mitigate | Restrict JSON body size to 100KB using `express.json({ limit: '100kb' })` |
| T-01-07 | Brute Force Attacks | `src/routes/auth-routes.js:login` | mitigate | Throttle failed attempts by IP (max 5 per 15 min), returning 429 with retry-after header |
| T-01-08 | Information Disclosure | `src/server.js` error handler | mitigate | Global error handler sanitizes stack traces and returns generic error message in production |
</threat_model>
