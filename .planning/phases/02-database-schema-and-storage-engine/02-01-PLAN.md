## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | `src/db.js` SQL queries | mitigate | Use parameterized statements (`db.prepare(...).run/all(...)`) for all dynamic inputs |
| T-02-02 | Information Disclosure | Database file storage | mitigate | Ensure storage directory is placed outside public static root (`data/` vs `public/`) |
| T-02-03 | Denial of Service | SQLite locking / concurrency | mitigate | Enable `journal_mode = WAL` and `synchronous = NORMAL` for non-blocking concurrent reads |
</threat_model>
